# 🧰 ملفات البناء والتعديل

> كل اللي محتاجه عشان تعدّل النسخة وتطلع نسخة جديدة موقعة بنفسك.

## 📁 محتويات المجلد

| العنصر | الوظيفة |
|---|---|
| `rebuild-and-sign.ps1` | السكربت الرئيسي: يبني النسخة من السورس المفكوك → يحاذي → يوقّع → يتأكد |
| `rebuild-and-sign.cmd` | غلاف: دوس مرتين عليه وهو يشغّل السكربت تلقائيًا |
| `decode-apk.ps1` | فك أي APK جديد (لو نزلت نسخة أحدث مستقبلًا) |
| `ayumod-release.jks` | كيستور التوقيع الخاص بإصداراتك المعدلة |
| `tools\apktool.jar` | أداة الفك والبناء (2.11.1) |
| `tools\jadx\` | أداة قراءة الكود بجافا (GUI + سطر أوامر) |

## 🔑 بيانات التوقيع (احتفظ بيها — مهمة!)

```
الكيستور:       ayumod-release.jks
Alias:          ayumod
كلمة السر:      كلمة-السر-محفوظة-عند-صاحب-المشروع          (للـ keystore والـ key بنفس القيمة)
```

- **كل النسخ اللي هتبنيها بالكيستور ده هتثبت فوق بعضها عادي** (نفس التوقيع).
- لو غيّرت الكيستور أو ضاع منك: هتضطر تشيل التطبيق وتثبته من جديد (مع تصدير/استيراد قاعدة بيانات أيوجرام).
- **خد نسخة احتياطية من ملف `ayumod-release.jks` دلوقتي** (خزّنه في مكان آمن). متحطهوش على GitHub علني.

## 🚀 طريقة الاستخدام

### أ) تعديل + إعادة بناء
1. عدّل اللي عايزه في السورس المفكوك:
   - **النصوص العربية**: `02-السورس-المفكوك\apktool-unpacked\assets\ayu_locales\values-ar\ayu.xml`
   - **النصوص العامة**: `...\apktool-unpacked\res\values\strings.xml`
   - **الكود**: ملفات `.smali` في نفس المجلد (تفاصيل في `01-مميزات-النسخة\04-خريطة-الكود-للتعديل.md`)
   - **رقم الإصدار**: `...\apktool-unpacked\apktool.yml`
2. شغّل `rebuild-and-sign.cmd` (أو `.\rebuild-and-sign.ps1` من بور شل).
3. النسخة الجديدة هتلاقيها في `03-النسخ-الجاهزة\` — انقلها للموبايل وثبّت.

### ب) فك نسخة أحدث مستقبلًا (لما ينزل تحديث رسمي جديد)
```powershell
cd "04-ملفات-البناء"
.\decode-apk.ps1 -Apk "C:\Users\Fazah\Downloads\AyuGram-XX.apk" -OutDir "C:\work\unpack-new"
```
وبعدين تنقل تعديلاتك من النسخة القديمة للجديدة، وتبني من `C:\work\unpack-new`:
```powershell
.\rebuild-and-sign.ps1 -DecodedDir "C:\work\unpack-new" -Name "AyuGram-XX-mod"
```

### ج) قراءة الكود بسهولة (جافا)
- افتح `tools\jadx\bin\jadx-gui.bat` واختار الـAPK الأصلي — هيطلعلك كل الكود بجافا قابلة للبحث والقراءة.

## ⚙️ متطلبات التشغيل (نفس جهازك)

- **JDK 17**: مثبت في `C:\Java\jdk17`
- **Android Build-Tools**: في `C:\Android\android-sdk\build-tools\37.0.0`
- لو نقلت أي حاجة من دول لمكان تاني: عدّل مسارات `JdkPath` / `BuildTools` في أول السكربت.

## ⚠️ ملاحظات مهمة

1. **خد نسخة احتياطية من `C:\work\unpack-apktool` قبل أي تعديل كبير** — رجعته بسهولة لو حصلت مشكلة.
2. **طوّل بالك على التعديلات الصغيرة** — عدّل حاجة واحدة، ابنِ، جرّب، وبعدين كمّل. أنجح وأسهل في اكتشاف الأخطاء.
3. لو البناء رمى أخطاء smali: يحدد لك اسم الملف والسطر — صلّحه وأعد التشغيل.
4. ملفات المرفقات الكبيرة (assets) بتزود وقت البناء — التجربة العادية ثواني/دقايق على جهازك.
5. للسورس الكامل: الفك الطويل القديم موجود في `C:\work\unpack-apktool` برضه (نفس الملفات اللي جوه اختصار `02`).
