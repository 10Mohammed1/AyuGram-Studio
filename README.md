## ℹ️ حقائق سريعة
- النسخة = آخر إصدار رسمي (5 أكتوبر 2026، مبنية على exteraGram 12.10.6). السورس الرسمي غير منشور — فك النسخة هو الطريق العملي (واتعمل بالكامل).
- تعديلات النسخة المعدلة: رقم بناء `71130` + علامة "(نسخة AyuMod)" في الإعدادات فقط — مفيش أي تغيير وظيفي.
- التوقيع: الرسمية بتوقيع المطور الرسمي (تحديثات فوقها عادي)، والنسخة المعدلة بتوقيع محلي (الأرشيف المشفّر بتاعه في `04`).

## ⚠️ تحذيرات
- نسخة المود **بتوقيع مختلف** عن الرسمية → أول تركيب لازم يكون بعد إزالة النسخة القديمة، ومعاها **تصدير بيانات AyuGram** قبل الإزالة واستيرادها بعد التركيب.
- الكيستور الحقيقي **مش** في المستودع (نسخة مشفرة فقط) — كلمة السر عند صاحب المشروع.
- المستودع عام: به **صفر** بيانات شخصية أو مفاتيح غير مشفرة.
