## 🧪 وصفات جاهزة (مجربة على النسخة دي)

### 1) تعديل نص (أبسط تعديل ممكن) — مجرَّب ✅
عدّلنا فعليًا نص التوقيع في الإعدادات كمثال:
```
assets/ayu_locales/values-ar/ayu.xml:
  قبل: <string name="SettingsWatermark">يتم تطوير وصيانة AyuGram بواسطة Radolyn Labs.</string>
  بعد: <string name="SettingsWatermark">يتم تطوير وصيانة AyuGram بواسطة Radolyn Labs. (نسخة AyuMod)</string>
```
بعد أي تعديل نصي: أعد البناء بالسكربت `04-ملفات-البناء\rebuild-and-sign.ps1`.

### 2) تغيير رقم الإصدار
```yaml
# apktool.yml
versionInfo:
  versionCode: 71131      ← زوّد واحد
  versionName: 12.10.6    ← سيبها زي ما هي أو غيّرها
```

### 3) إيقاف "طلب التحديث" نهائيًا (اختياري — قراءة الخطر الأول!)
في `smali/org/telegram/messenger/BuildVars.smali` بدّل:
```
const-string v0, "20261005"    →    const-string v0, "99999999"
```
⚠️ **النتيجة**: التطبيق هيشوف نفسه دايمًا أحدث نسخة ومش هيقولك على أي تحديث رسمي بعد كده.
**الأنصح**: سيبها زي ما هي، ولما تنزل نسخة أحدث نزّلها من القناة الرسمية.

### 4) تغيير أيقونة التطبيق الافتراضية
- الأيقونات في `res/mipmap-anydpi-v26/ic_launcher.xml` + مجلدات `mipmap-*dpi/`.
- استبدل الصور بنفس الأسماء والأحجام (أو عدّل ملفات adaptive icon).

### 5) إيقاف/تعديل مميزة معينة (الطريقة لفيتشر كامب)
1. **اعرف اسم المميزة**: دوّر على نصها العربي في `07-...` لا، في `assets/ayu_locales/values-ar/ayu.xml` (مثلاً `SaveDeletedMessages`).
2. **اعرف المفتاح**: نفس الاسم غالبًا اسم مفتاح الإعداد (SharedPreferences) — دوّر عنه في `jadx-java` أو في الـsmali.
3. **عدّل السلوك**: في `smali*` المقابل — أو الأسهل: عطّل الخيار من الافتراضي بجعل قيمته false في كود القراءة.
4. **ابنِ ووقّع وثبّت تجربة** (السكربت بيشرح كل حاجة).

### 6) خطوات البناء الكاملة (باختصار — التفاصيل في سكربت 04)
```powershell
# 1) بناء
java -jar apktool.jar b "C:\work\unpack-apktool" -o mod-unsigned.apk
# 2) محاذاة
zipalign.exe -f -p 4 mod-unsigned.apk mod-aligned.apk
# 3) توقيع
apksigner.bat sign --ks ayumod-release.jks --ks-pass pass:... --out mod-signed.apk mod-aligned.apk
# 4) تحقق
apksigner.bat verify --verbose mod-signed.apk
```

## 📋 ملاحظات مهمة للتعديل الآمن

1. **انسخ `C:\work\unpack-apktool` كنسخة احتياطية قبل أي تعديل كبير** (أو استخدم git محلي جواه).
2. متغيّرش أسماء الملفات أو الحزم في `smali` إلا وأنت فاهم — التطبيق بيحمّل الكلاسات بالاسم من المانيفست والموارد.
3. بعد أي تعديل في الـ**موارد** أو **assets**، البناء بيعيد ضغط كل حاجة أوتوماتيك — لو حصلت مشكلة غريبة، ارجع للتعديل الأخير بالعكس.
4. التثبيت فوق النسخة القديمة **مستحيل** مع اختلاف التوقيع — شيل القديمة الأول (مع تصدير قاعدة بيانات أيوجرام من الإعدادات).
5. في نسخة jadx، الكود أسهل بكثير للقراءة (جافا) — استخدمها للفهم، والـsmali للتعديل الفعلي.
