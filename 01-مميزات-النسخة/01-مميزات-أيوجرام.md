## 👻 وضع الشبح (Ghost Mode)

| المميزة | الشرح |
|---|---|
| **إخفاء أنك متصل** | التطبيق ميبعتش باكت "متصل" للسيرفر — تظهر للناس غير متصل دائمًا |
| **إخفاء قراءة الرسائل** | الرسائل اللي تفتحها مش تتعلم كمقروءة عند الطرف الآخر |
| **إخفاء مشاهدة القصص** | مشاهداتك للقصص مش بتظهر لصاحب القصة |
| **إخفاء "جاري الكتابة..."** | مؤشر الكتابة مش بيتبعت |
| **اذهب دون اتصال تلقائي** | لما تخرج من وضع الشبح/التطبيق يبعت باكت "غير متصل" فورًا |
| **القراءة عند التفاعل** | يعلّم الرسالة كمقروءة تلقائيًا عند: **إرسال** رسالة / **تفاعل** / **استفتاء** |
| **الرسائل المجدولة** | يجدول رسائلك تلقائيًا (~12 ثانية، أطول للوسائط) فتبعت بدون ما تظهر متصل — مع تحذير من الشبكات غير المستقرة |
| **إرسال بدون صوت** | خيارات: أبدًا / عند وضع الشبح / دائمًا |
| **تنبيه وضع الشبح للقصة** | يسألك "تفعّل الشبح قبل ما تشوف القصة؟" |
| **إعدادات عامة أو فردية** | نفس إعدادات الشبح لكل الحسابات، أو إعدادات مستقلة لكل حساب |
| **عرض حالة وضع الشبح** | حالة الشبح تظهر في عنوان قائمة المحادثات |
| **اختصار ادخل وضع الشبح** | تشغيل/إيقاف سريع من أي مكان |
| **اضغط مطولًا على أي خيار** لمنعه من التغير عند تفعيل/إلغاء وضع الشبح كله (وكمان مع SHIFT على الكمبيوتر المنزلي) |
| **علامات القراءة المحلية/السيرفر** | تحكم يدوي في LRead/SRead لكل محادثة |

## 🕵️ وضع التجسس (Spy) — الرسائل المحذوفة والمعدلة

| المميزة | الشرح |
|---|---|
| **الاحتفاظ بالرسائل المحذوفة** | أي رسالة تتحذف من أي محادثة تتخزن محليًا وتظهر لك بعلامة "محذوفة" |
| **الاحتفاظ بسجل التعديلات** | تشوف كل نسخ الرسالة المعدلة (الأحداث/السجل) |
| **حفظ المرفقات** | تحميل الوسائط للمحذوفة: محادثات خاصة / قنوات عامة وخاصة / مجموعات عامة وخاصة — بتحكم لكل نوع |
| **الاستثناءات (Manage Exclusions)** | حدد مين يتسجل ومين لأ: وضعين (فقط المختارة / الكل ما عدا المستثبعدين) + إضافة أنواع كاملة: محادثات بوتات، بوتات في المجموعات، محادثات سرية، أو محادثات فردية |
| **حد أقصى لحجم مجلد المرفقات** | لما يوصل الحد، أقدم المرفقات تتمسح تلقائيًا — مع عرض الاستهلاك (X من Y) |
| **حدود حجم الوسائط** | حد أقصى للتحميل على بيانات الموبايل وعلى الواي فاي |
| **مجلد المرفقات المخصص** | اختار فولدر التخزين بنفسك |
| **حفظ تاريخ القراءة** | يسجل محليًا إمتى اتعلمت الرسالة كمقروءة (يظهر لو تلجرام مفيش عنده تاريخ) |
| **حفظ تاريخ آخر ظهور** | يسجل آخر نشاط للمستخدمين اللي مخبيين ظهورهم — تقدير تقريبي جدًا |
| **متصل الآن (Peek Online)** | أمر سريع يعرض حالة اتصال المستخدم + تحديث تلقائي |
| **تاريخ الحذف / تاريخ القراءة / تاريخ قراءة المحتوى** | أوامر في قائمة الرسالة تعرض التواريخ دي |
| **مسح المحذوفة / مشاهدة محذوفة** | إدارة الرسائل المخزنة لكل محادثة |
| **حذف رسائلي** | أمر يحذف كل رسائلك من مجموعة |
| **قراءة الرسائل (ReadUntil)** | تعليم كل الرسائل كمقروءة لحد نقطة |
| **رسائل المستخدم** | عرض سريع لكل رسائل مستخدم معين |
| **حرق (ExpireMedia)** | تشغيل/عرض وسائط ذاتية التدمير بدون قيود (مشاهدة واحدة/تشغيل واحد — تتفتح عادي وتفضل مقروءة) |
| **إخفاء رسائلي من المشاهدات** | HideNextViews — يخفي مشاهداتك بشكل دائم لحد ما تقفل الشبح |

| **استيراد/تصدير الفلاتر** | من الحافظة أو من رابط URL (ونشر على dpaste.com) |
| **شاشة مقارنة التغييرات** | قايمة بالفلاتر الجديدة/المحذوفة/المستبعدة قبل التطبيق |
| **أداة تصحيح Regex** | فتح regex101.com مباشرة + رسالة خطأ في الصيغة |
| **الفلاتر المستبعدة** | إدارة الاستثناءات (تصدير/استيراد/مسح) |

## 🗓️ ميزة تواريخ التسجيل (Registration Dates)

- تعرض **تاريخ انشاء/تسجيل أي مستخدم** في تلجرام (باوندري تقديري) — ويظهر في البروفايل.
- بتشتغل من قاعدة بيانات مدمجة `registration_dates.bin` (مفكوكة بالكامل في `05-ملفات-البيانات-والقواعد.md`).
- لو المستخدم مش موجود محليًا، التطبيق **بيسأل سيرفر exteraAPI** ويجيب تاريخه بالظبط.

## ⬆️ نظام تحديث AyuGram

- الإعدادات فيها زر **"تحديث AyuGram"** — بيقارن نسختك (AYU_VERSION بتاريخ البناء `20261005`) بأحدث نسخة معلنة.
- التحديثات بتوصل عن طريق **قناة تلجرام** (transport) وقاعدة **RemoteConfig** — لو فشلت لـ14 يوم بيفل باك لـhttp.
- عشان كده: **طالما نسختك بتاريخ 20261005 (الأحدث)، مش المفروض يطلب تحديث**. لو ظهرلك طلب تحديث، يعني تطبيقك المثبت أقدم من كده — ثبّت النسخة الرسمية من مجلد `03`.
